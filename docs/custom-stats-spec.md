## 0. 已确认决策记录

| # | 决策点 | 结论 |
|---|--------|------|
| D1 | 执行位置 | 端上本地执行。应用为 local-first（Dexie）+ E2EE，服务端无明文数据；端上执行天然满足「数据不出设备」 |
| D2 | 沙箱选型 | QuickJS(WASM) 跑在 Web Worker 内：访客代码零 ambient 权限（无网络/DOM/存储），真隔离；裸 Worker（有 fetch/indexedDB 外泄面）与 iframe+CSP（工程脆、依赖配置正确）均否决 |
| D3 | 数据两路分离 | LLM 只见「契约文档 + 字段字典 + 每表 2~3 行样例」；**全量数据只在沙箱执行时本地注入**。现有 copilot contextSummary ≤12KB 体系不动，全量明细永不出设备、不进 prompt |
| D4 | 生成入口 | 复用现有 AI 聊天框，无新输入框。LLM 通过既有 actions 管线返回新动作类型 `run_custom_stat` |
| D5 | 动作分级 | `run_custom_stat` 为 **auto 级**：沙箱内只读计算 + 本地渲染，无业务副作用，与 notify/focus_block 同级；真正有副作用的「保存」由用户显式点击 |
| D6 | 信任模型 | 沙箱管安全（无网络/无存储/时限/内存上限），**保存 = 唯一的明确信任动作**。用户看效果拍板，不要求读代码（代码折叠可查，透明但不设卡） |
| D7 | 结果形态（XOR） | 一次生成 = **一个标题卡 或 一个统计图表**（二选一，判别联合）；P0 无表格 |
| D8 | 编辑权 | 用户不编辑代码；保存后定义**不可变**（不提供 updateCode）；修改只走「重新生成」 |
| D9 | 重新生成 | 复用存储的提示词种子（可追加修改要求）→ 新草稿 → 看效果 → 另存新定义或替换原定义（钉选状态迁移） |
| D10 | 提示词留存 | 生成时 AI 同步产出规范化 `prompt` 种子（≤2KB）并随定义存储；删除时弹层提示可复制保存 |
| D11 | 画廊 | 双区钉选：数字卡区（card 类）/ 图表区（chart 类），分区由结果 kind 唯一决定；每区默认 5 条、分页「加载更多」；另有「全部定义」折叠列表（未钉选 + 管理入口） |
| D12 | 新鲜度 | `lastResult` 随定义缓存（stale-while-revalidate）：先秒显缓存（带「截至 HH:mm」角标），后台刷新原位替换；刷新范围 = **已加载条目**（分页天然限定，视口外不刷），分批串行（单批 ≤6）；Worker 内 ctx 一次注入多次复用，批量刷新 = 1× ctx 注入 + N× 毫秒级执行 |
| D13 | 新内容标识 | NEW 角标 + 高亮描边（`pinnedAt > lastSeenAt`，localStorage 记录）；页外新内容显示「顶部有 N 条」胶囊 |
| D14 | 图表库 | recharts（唯一新增运行时依赖），React.lazy 懒加载独立 chunk，主包零影响 |
| D15 | 迭代协议 | 单码覆盖模式：AI 每轮返回**完整替换代码**（不做 diff）；迭代 prompt = prompt 种子（原始需求锚点）+ 当前 code + 本次反馈 |
| D16 | 六项默认值 | ① 迭代带 code（防口径漂移）② ctx 含全量流水 `txns` ③ code 形态 = 完整箭头函数表达式 ④ QuickJS RELEASE_SYNC ⑤ tone 色彩映射红涨绿跌（A股习惯）⑥ 草稿刷新即失不加 beforeunload 拦截，靠「未保存」视觉标识 |
| D17 | 服务端持久化 | 保存的定义登录后备份到服务端数据库（**非用户核心数据**：不含账本流水，明文 JSONB 直存，不走 E2EE 快照通道、无 MEK 依赖）：单条 upsert/delete + 打开画廊对账，`updatedAt` LWW、删除优先；未登录保持纯本地。契约见 `custom-stats-server-sync.md` |

## 1. 背景与问题

### 1.1 现状痛点

1. **统计页是写死的**：数据统计页现有指标（总收益/胜率/平均每轮收益/费用合计等）为硬编码，用户真正想问的问题层出不穷——「各股做T收益排行」「按月胜率趋势」「星期几做T最容易亏」「空仓日占比」——每一个都要走开发排期。
2. **AI 聊天只能「说」不能「算」**：现有 Copilot 上下文为 ≤12KB 的摘要快照（最近 10 条明细），LLM 只能基于样例做定性回答，无法对全量数据做精确统计，更无法把结果固化成可反复查看的图表。
3. **固定图表永远对不上个体需求**：预置图表维度（时间/股票/模式）的组合空间是笛卡尔积，不可能穷举。

### 1.2 机会

- 用户数据全部在端上（Dexie），全量统计可以在本地完成；
- 项目已有成熟的 Copilot 动作管线（LLM 输出按不可信输入处理、白名单+守卫+分级）和后端提示词模板管理体系；
- 两个前提叠加：让 AI 生成统计代码、在端上沙箱执行，是本项目的自然延伸，而非外来的重架构。

## 2. 目标与非目标

### 2.1 目标

1. **个性化统计自助化**：用户用自然语言描述统计需求，AI 生成统计代码，端上沙箱对**全量本地数据**执行，以标题卡/统计图呈现结果。
2. **留存与复用**：满意的统计一键保存为「统计定义」，画廊双区钉选常驻展示，数据变化后一键/自动刷新即得最新数字。
3. **安全底线**：AI 生成代码在强隔离沙箱中执行（无网络、无存储访问、资源受限）；全量数据永不出设备、不进 LLM prompt。
4. **零门槛信任**：用户全程不需要读代码——看效果拍板；「保存」是唯一需要明确点击的信任动作。

### 2.2 非目标（本期不做）

- 统计定义的多端同步（P1：登记进 WebDAV/服务端快照两条同步链路）
- 表格类结果（P1 视需求回归，schemaVersion 演进）
- 统计定义导入导出 / 模板市场（P2）
- 参数化统计（运行时传参，如「指定某只股票」——P1）
- 后端执行统计代码（架构上永久排除：服务端无明文数据）

## 4. 功能需求

### FR1 聊天生成（入口）

- 用户在现有 AI 聊天框输入统计需求（处于 statistics scope 或任意 scope 均可发起）；
- LLM 返回 `run_custom_stat` 动作（auto 级），payload 含 `name`（≤40 字符）/ `description`（口径说明）/ `prompt`（规范化需求种子 ≤2048 UTF-8 字节）/ `code`（≤16384 UTF-8 字节，`(ctx) => {...}` 完整箭头函数表达式）；
- 前端守卫校验 payload 形状与长度上限，非法载荷静默丢弃（沿用 copilotActions 白名单纪律）；
- 复合需求（如「各股排行 + 整体胜率」）：LLM 可在同一轮回多个 action（沿用 `COPILOT_ACTION_LIMIT = 5` 上限）。

### FR2 沙箱执行与结果展示

- 执行前夹具预跑：空数组夹具 + 2~3 行样例夹具，任一失败进入修复流程，用户不看到崩溃；
- 正式执行：组装全量 ctx（一次性）→ QuickJS Worker 沙箱运行 → Result Guard 归一化 → 结果面板渲染；
- 结果面板：标题（name）+ 口径说明（description）+ 标题卡（kpis ≤3）或统计图（bar/line/pie）+「AI 生成代码」折叠区 + Loading/错误态；
- 错误态提供「一键让 AI 修复」入口（携带沙箱错误栈 + 代码 + 反馈）。

### FR3 草稿态与迭代

- 生成结果先入**草稿态**（内存态，单槽位，刷新即失，与 actions「在线在场态」语义一致）；
- **覆盖规则**：旧草稿未保存时又生成新统计 → 新草稿自动覆盖旧槽位，toast 轻提示「已加载新生成的统计草稿，未保存的旧草稿已丢弃」（不弹拦截确认，草稿为低承诺产物）；
- 用户以自然语言反馈（「按月分组」「去掉手续费」），前端按迭代协议组装请求（D15）：prompt 种子 + 当前 code + 本次反馈，AI 返回完整替换代码并自动重跑；
- 草稿显示「第 N 版」attempt 计数；连续 ≥5 版不收敛给轻提示（建议换个描述或先保存最接近版本）；
- 草稿面板提供：[保存] [继续调整（输入框继续说）] [丢弃]。

### FR4 保存（信任动作）

- 用户显式点击「保存」→ 弹层确认名称（默认 LLM 建议名，可改）与描述 → 写入本地 `custom_stats` 表；
- 定义**不可变**：保存后无代码编辑入口（不可变性由服务接口面保证——不提供 updateCode）；
- 「重新生成」场景的保存弹层提供双选项：[另存为新定义] / [替换原定义]（替换 = 存新行 + 软删旧行 + 钉选状态按新 kind 迁移）；
- 保存后草稿清空，结果面板标记「已保存」，提供跳转画廊入口。

### FR5 画廊（双区钉选）

- 位置：数据统计页新增「自定义统计」tab（`'trades' | 'positions' | 'custom'`）；
- **数字卡区**：钉选的 card 类定义，默认 5 条，分页「加载更多」；每条渲染为紧凑数字卡（kpis + 截至时间角标）；
- **图表区**：钉选的 chart 类定义，默认 5 条，分页「加载更多」；每条渲染为完整图表块；
- 分区由定义的 `lastResult.kind` 唯一决定，钉选字段仅 `pinned/pinnedAt`；区内排序 `pinnedAt` 倒序；
- 钉选不设硬上限（分页消化）；未钉选定义在「全部定义」折叠列表（同样分页），含管理入口：运行 / 重新生成 / 钉选 / 删除。

### FR6 常驻展示与新鲜度

- 画廊优先渲染缓存 `lastResult`（带「截至 HH:mm」角标），打开页面后台刷新**已加载条目**（分页天然限定刷新规模，视口外未加载条目不刷）原位替换；
- 批量刷新 = 1× 全量 ctx + N× 沙箱执行：ctx 经 `ctx` 消息**一次注入 Worker、批次内复用**（避免逐条重传重 parse）；执行**分批串行**（单批 ≤6，批间让出主线程），每条完成即原子写回并渐进替换对应卡片；
- 提供手动刷新按钮（含单条定义的刷新）；
- 沙箱 Worker 单例常驻（copilot 浮窗打开时预热）。

### FR7 删除与提示词保全

- 删除为软删（`isDeleted=1`），确认弹层展示该定义的生成提示词，提供 [复制提示词]（剪贴板，纯文本 ≤2KB）；
- 弹层文案明确「该统计的生成提示词将一并删除」；
- 复制的提示词贴回聊天框即可在任何时候重建该统计。

### FR8 重新生成

- 定义卡「重新生成」→ 打开聊天，注入存储的 prompt 种子 → 用户可追加修改要求 → 走 FR1~FR4 流程；
- 与 FR4 的另存/替换双选项衔接。

### FR9 新内容标识

- 钉选条目 `pinnedAt > lastSeenAt`（localStorage）→ NEW 角标 + 高亮描边，查看该区后淡出；
- 用户已翻页时新钉选到达 → 区头胶囊「↑ 顶部有 N 条新钉选，点击查看」。

### FR10 空态与兜底

- 库内无数据时生成统计：夹具拦截 + 结果面板友好空态（引导先录入数据）；
- 图表数据为空数组：渲染空态组件，不报错；
- schemaVersion 不匹配的旧定义：运行前编译预检失败 → 明确报错 + 「AI 修复」入口。

## 5. 非功能需求

### 5.1 安全与隐私

| 项 | 要求 |
|---|---|
| 沙箱隔离 | 访客代码零 ambient 权限：无网络、无 DOM、无存储、无宿主对象；仅可见注入的 ctx 与 helpers |
| 资源限制 | CPU 时限（interrupt，P0 建议 500ms/次执行）+ 内存上限（64~128MB）+ Worker terminate 兜底 |
| 数据边界 | 全量数据只在端上注入沙箱；LLM 请求仅含契约 + 字典 + ≤3 行/表样例；全量明细不落日志 |
| 输出防线 | Result Guard 归一化（纯文本强制、tone 白名单、行键防原型污染、isFinite 归一、截断+标注）；渲染层 React 声明式纯文本，禁止任何 HTML 注入路径 |
| 人审在环 | 保存为显式动作；已存定义免确认直跑（物理上同一沙箱 runner，隔离强度不因信任降级） |

### 5.2 性能

| 场景 | 预算 |
|---|---|
| 打开画廊（首屏 5+5 条） | 缓存渲染毫秒级；后台批量刷新（10 条）≈ 1× 取数 + N× 毫秒级执行，1~2s 内完成，用户无感 |
| 单次运行 | 暖路径几十 ms ~ 1s（大头是全量数据 JSON 注入与 QuickJS parse，非代码执行） |
| 沙箱冷启动 | copilot 浮窗打开时预热加载 wasm + 初始化 Worker，用户首次生成时已就绪 |
| 画廊分页 | 元数据轻量读入 + UI 层切片（页大小 5），切换成本毫秒级 |

### 5.3 兼容与工程

- recharts 为唯一新增运行时依赖（懒加载 chunk，主包零影响）；
- QuickJS wasm 资产纳入 PWA 预缓存（workbox `globPatterns` 补 `.wasm`），保障离线首用；
- 分层护栏合规：views 不碰 db（R1）、utils 不碰 store/db（R2）、types 零依赖（R3）；
- 新文件命名带 `customStat` 关键词，`map:features` 自动归组。

## 6. 验收标准（P0 DoD）

- [ ] 聊天框输入统计需求 → 结果面板出现标题卡或图表（XOR），全程无需读代码；
- [ ] 结果基于全量数据计算：构造边界用例（如某股票仅 1 条归档轮），统计数字与手工核算一致；
- [ ] 草稿迭代 ≥2 轮后结果正确收敛，第 N 版计数可见；
- [ ] 保存后画廊对应区出现钉选条目；重启应用后打开统计页，缓存结果秒显且后台刷新为最新；
- [ ] 删除弹层可复制提示词，复制内容贴回聊天框可重建等价统计；
- [ ] 空库 / 空数据 / 代码死循环（测试桩）三种异常路径均不崩溃，有友好态；
- [ ] 全量数据不出设备：抓包验证 LLM 请求仅含契约字典与样例行；
- [ ] `npx tsc --noEmit` 零错误；`npm test` 全绿（含新增用例）；`npm run check:arch` 通过。
